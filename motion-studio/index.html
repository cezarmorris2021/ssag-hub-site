Reality check

  1. The interface and local previews work without a subscription.
  2. Real AI dancing needs an NVIDIA CUDA GPU with the Motion Mirror model installed; there is no false CPU simulation mode.
  3. If GPU processing is unavailable, submission stays disabled rather than claiming a customer video was produced.
  4. Only a completed, downloaded MP4 counts as an end-to-end successful job.
Security and media retention

Photo, video and API key remain local until Generate is pressed. The configurable worker requires a secret and a TLS connection for remote use. The supplied worker implementation stores private job files, expires them after 24 hours, and supports immediate manual deletion. No child or customer media is embedded in the website source.
